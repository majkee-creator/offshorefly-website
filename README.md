# Offshore Fly premium website

## Upload to GitHub
1. Create a public repository, for example `offshorefly-website`.
2. Upload the **contents of this folder** to the repository root. Do not upload the outer folder itself.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, `main`, `/ (root)` and save.
5. Test the temporary GitHub Pages URL.
6. In Pages, set the custom domain to `offshorefly.app`.
7. Update the Websupport DNS records using the values GitHub Pages shows.
8. Enable **Enforce HTTPS** after DNS becomes active.

## App Store URLs
- Privacy: `https://offshorefly.app/privacy/`
- Support: `https://offshorefly.app/support/`
- Terms: `https://offshorefly.app/terms/`

## Before publishing
- Create and verify `support@offshorefly.app`, or replace that email address in the HTML files.
- Review the legal text against the final app’s actual data flows.
- Replace “Coming soon to the App Store” after release.
